# fraudes-examens-analyse-risques
sujet : fraudes aux examens et conséquences sur les compétences des diplômés.



Outils : Google Forms, Google Sheets, Excel, Python (Google Colab), Word, PowerPoint.



Méthode : diagramme Ishikawa 6M, analyse statistique, scores Xi/Yi, criticité Ci et cartographie.



Résultats : 17 réponses, 11 risques évalués, R1/R7/R9 en zone IV.



Limites : R4 non mesuré et R10/R11 évalués avec les mêmes questions.
